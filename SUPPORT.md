# Support

Start with `smesh doctor`, `smesh logs`, and the
[README troubleshooting table](https://github.com/SkilakLabs/smesh/blob/main/README.md#troubleshooting).

[File a bug](https://github.com/SkilakLabs/smesh/issues/new/choose) with the output of `smesh version`,
OS and architecture, install method, client, steps to reproduce, expected and
observed behavior, and the output of `smesh doctor`. A short `smesh logs` excerpt
can help. Review all output for personal data before posting. Never paste secrets,
tokens, prompts, file contents or the real value Mesh matched.

Report vulnerabilities and deliberate bypasses [privately](https://github.com/SkilakLabs/smesh/security/advisories/new).
