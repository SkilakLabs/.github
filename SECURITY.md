# Security

Report vulnerabilities and deliberate bypasses [privately](https://github.com/SkilakLabs/smesh/security/advisories/new).
Never report them in public issues.

Include the Mesh version, OS and architecture, affected client and version,
steps to reproduce with made-up values, and the expected and observed behavior.
Do not include secrets, prompts, personal data or file contents.

Only the latest release is supported.
